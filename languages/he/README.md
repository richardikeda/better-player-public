# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

שנו את מהירות ההפעלה ואת עוצמת הקול בסרטוני Instagram, נגנו קטעים בלולאה והורידו סרטונים תואמים.

**[התקנה · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [אתר אינטרנט](https://richardikeda.github.io/better-player-public/languages/he/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [פרטיות (בפורטוגזית)](https://richardikeda.github.io/better-player-public/#privacidade)

## תכונות

- **השמעה וצליל**: השהה, שנה את המהירות, התאם את עוצמת הקול, גרור את ציר הזמן או קפוץ 5 שניות אחורה או קדימה.
- **הפעל מחדש את מה שחשוב**: לולאה סרטון שלם או סמן A ו-B כדי לחזור על הקטע הזה.
- **דרכים נוספות לצפייה**: עבור למסך מלא או השאר את הסרטון בחלון תמונה-בתמונה צף כאשר זמין.
- **הפוך אותו לשלך**: בחר מתוך 10 ערכות נושא, מה-Better Minimal הקומפקטי ועד לפקדים הגדולים יותר של Better XG. הגדר מתי הסרגל מסתתר והפעל את קיצורי המקלדת אם תרצה.
- **שמירת וידאו אופציונלית**: הורד קבצי וידאו תואמים או הקלט קליפ קצר באופן מקומי כאשר זה נתמך. שמור רק תוכן שיש לך הרשאה להעתיק.

## היכן להתקין

הדפדפנים למטה תומכים בהתקנה דרך חנות האינטרנט של Chrome. Better Player נבדק ב-Chrome וב-Edge ב-Windows.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** התקנת חנות מסמכים של Vivaldi ו-Yandex ב-Android. Better Player עדיין זקוק לבדיקה בדפדפנים הניידים הללו. ב-Vivaldi, הפעל את אתר שולחן העבודה. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox ו-Safari משתמשים בערוצי הפצה נפרדים. מהדורת Firefox נמצאת בבדיקה.

## תמיכה

לאחר ההתקנה, פתח את אינסטגרם בדפדפן שלך. לחץ על הסמל Better Player כדי להגדיר את הפקדים. בעת דיווח על בעיה, כלול את הדפדפן, הגרסה והשלבים לשחזור שלה.
