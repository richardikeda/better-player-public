# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Ayusin ang bilis at lakas ng tunog ng mga video sa Instagram, ulitin ang mga bahagi, at i-download ang mga tugmang video.

**[I-install · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [Website](https://richardikeda.github.io/better-player-public/languages/fil/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [Privacy (sa Portuguese)](https://richardikeda.github.io/better-player-public/#privacidade)

## Mga tampok

- **Pag-playback at tunog**: i-pause, baguhin ang bilis, ayusin ang volume, i-drag ang timeline, o tumalon nang 5 segundo pabalik o pasulong.
- **I-replay kung ano ang mahalaga**: i-loop ang isang buong video o markahan ang A at B para ulitin ang segment na iyon.
- **Higit pang paraan para manood**: lumipat sa fullscreen o panatilihin ang video sa isang lumulutang na Picture-in-Picture window kapag available.
- **Gawin itong sa iyo**: pumili mula sa 10 tema, mula sa compact na Better Minimal hanggang sa mas malalaking kontrol ng Better XG. Itakda kung kailan nagtatago ang bar at i-on ang mga keyboard shortcut kung gusto mo.
- **Opsyonal na pag-save ng video**: mag-download ng mga katugmang video file o magrekord ng maikling clip nang lokal kapag sinusuportahan. I-save lamang ang nilalaman na mayroon kang pahintulot na kopyahin.

## Kung saan i-install

Sinusuportahan ng mga browser sa ibaba ang pag-install sa pamamagitan ng Chrome Web Store. Ang Better Player ay nasubok sa Chrome at Edge sa Windows.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Vivaldi at Yandex Browser na nag-iimbak ng dokumento sa Android. Kailangan pa rin ng Better Player ng pagsubok sa mga mobile browser na ito. Sa Vivaldi, paganahin ang Desktop Site. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Gumagamit ang Firefox at Safari ng magkahiwalay na mga channel ng pamamahagi. Ang edisyon ng Firefox ay nasa pagsubok.

## Suporta

Pagkatapos mag-install, buksan ang Instagram sa iyong browser. I-click ang icon na Better Player para i-configure ang mga kontrol. Kapag nag-uulat ng problema, isama ang iyong browser, bersyon, at mga hakbang upang muling gawin ito.
