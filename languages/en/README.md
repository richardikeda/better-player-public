# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Adjust playback speed and volume on Instagram, loop a section and download compatible videos.

**[Install · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [Site](https://richardikeda.github.io/better-player-public/languages/en/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [Privacy (Portuguese)](https://richardikeda.github.io/better-player-public/#privacidade)

## Features

- **Playback**. Adjust speed, volume, playback position, and A–B looping. Use full screen or picture-in-picture where available.
- **Customization**. Choose from 10 themes and set how long the controls stay visible.
- **Optional saving**. Download compatible videos or record clips locally where the browser allows it.

## Where to install

The browsers below support installation through the store. Better Player has been tested on Chrome and Edge on Windows.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Vivaldi and Yandex Browser document store installation on Android. Better Player still needs testing in these mobile browsers. In Vivaldi, enable Desktop Site. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox and Safari use separate distribution channels. The Firefox edition is in testing.

## Support

After installing, open Instagram in your browser. Click the Better Player icon to configure the controls. For support, include your browser, version, and steps to reproduce the problem.
