# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Ajuste a velocidade e o volume dos vídeos do Instagram, repita excertos e descarregue vídeos compatíveis.

**[Instalar · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [Site](https://richardikeda.github.io/better-player-public/languages/pt_PT/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [Privacidade (em português)](https://richardikeda.github.io/better-player-public/#privacidade)

## Recursos

- **Reprodução e som**: pausa, altera a velocidade, ajusta o volume, arrasta a linha do tempo ou salta 5 segundos para trás ou para a frente.
- **Repita o que interessa**: faça um loop de um vídeo inteiro ou marque A e B para repetir apenas esse segmento.
- **Mais formas de ver**: mude para ecrã inteiro ou mantenha o vídeo numa janela flutuante Picture-in-Picture, quando disponível.
- **Personalizar**: escolha entre 10 temas, desde o compacto Better Minimal até aos controlos maiores do Better XG. Defina quando a barra será ocultada e ative os atalhos de teclado, se desejar.
- **Guardar vídeo opcional**: transfira ficheiros de vídeo compatíveis ou grave um clipe curto localmente quando compatível. Guarde apenas o conteúdo que tem permissão para copiar.

## Onde instalar

Os browsers abaixo suportam a instalação através da Chrome Web Store. O Better Player foi testado no Chrome e Edge no Windows.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Instalação do armazenamento de documentos Vivaldi e Yandex Browser no Android. O Better Player ainda precisa de testes nestes browsers móveis. No Vivaldi, ative o Desktop Site. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

O Firefox e o Safari utilizam canais de distribuição separados. A edição Firefox está em testes.

## Suporte

Após a instalação, abra o Instagram no seu browser. Clique no ícone Better Player para configurar os controlos. Ao comunicar um problema, inclua o seu navegador, versão e passos para o reproduzir.
