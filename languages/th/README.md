# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

ปรับความเร็วและระดับเสียงของวิดีโอบน Instagram เล่นช่วงที่เลือกซ้ำ และดาวน์โหลดวิดีโอที่รองรับ

**[ติดตั้ง · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [เว็บไซต์](https://richardikeda.github.io/better-player-public/languages/th/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [ความเป็นส่วนตัว (ในภาษาโปรตุเกส)](https://richardikeda.github.io/better-player-public/#privacidade)

## คุณสมบัติ

- **การเล่นและเสียง**: หยุดชั่วคราว เปลี่ยนความเร็ว ปรับระดับเสียง ลากไทม์ไลน์ หรือข้ามไปข้างหลังหรือข้างหน้า 5 วินาที
- **เล่นซ้ำสิ่งที่สำคัญ**: วนวิดีโอทั้งหมดหรือทำเครื่องหมาย A และ B เพื่อเล่นซ้ำเฉพาะส่วนนั้น
- **วิธีรับชมเพิ่มเติม**: สลับไปยังโหมดเต็มหน้าจอหรือเก็บวิดีโอไว้ในหน้าต่างภาพซ้อนภาพแบบลอย หากมี
- **ทำให้เป็นของคุณ**: เลือกจาก 10 ธีม ตั้งแต่ Better Minimal ขนาดกะทัดรัดไปจนถึงส่วนควบคุมที่ใหญ่กว่าของ Better XG ตั้งค่าเวลาที่แถบซ่อนและเปิดแป้นพิมพ์ลัดหากต้องการ
- **การบันทึกวิดีโอเพิ่มเติม**: ดาวน์โหลดไฟล์วิดีโอที่เข้ากันได้หรือบันทึกคลิปสั้นในเครื่องเมื่อรองรับ บันทึกเฉพาะเนื้อหาที่คุณได้รับอนุญาตให้คัดลอกเท่านั้น

## ติดตั้งที่ไหน.

เบราว์เซอร์ด้านล่างรองรับการติดตั้งผ่าน Chrome เว็บสโตร์ Better Player ได้รับการทดสอบบน Chrome และ Edge บน Windows

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** การติดตั้งที่เก็บเอกสาร Vivaldi และ Yandex Browser บน Android Better Player ยังคงต้องการการทดสอบบนเบราว์เซอร์มือถือเหล่านี้ ในวิวาลดี ให้เปิดใช้งานไซต์เดสก์ท็อป [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox และ Safari ใช้ช่องทางการจัดจำหน่ายแยกกัน Firefox edition อยู่ระหว่างการทดสอบ

## สนับสนุน

หลังจากติดตั้งแล้ว ให้เปิด Instagram ในเบราว์เซอร์ของคุณ คลิกไอคอน Better Player เพื่อกำหนดค่าการควบคุม เมื่อรายงานปัญหา ให้ระบุเบราว์เซอร์ เวอร์ชัน และขั้นตอนในการทำซ้ำ
