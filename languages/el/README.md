# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Ρυθμίστε την ταχύτητα και την ένταση των βίντεο στο Instagram, επαναλάβετε αποσπάσματα και κατεβάστε συμβατά βίντεο.

**[Εγκατάσταση · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [Ιστοσελίδα](https://richardikeda.github.io/better-player-public/languages/el/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [Απόρρητο (στα Πορτογαλικά)](https://richardikeda.github.io/better-player-public/#privacidade)

## Χαρακτηριστικά

- **Αναπαραγωγή και ήχος**: παύση, αλλαγή ταχύτητας, ρύθμιση της έντασης, σύρετε τη γραμμή χρόνου ή μεταβείτε 5 δευτερόλεπτα πίσω ή μπροστά.
- **Επαναλάβετε ό,τι έχει σημασία**: επαναλάβετε ένα ολόκληρο βίντεο ή σημειώστε A και B για να επαναλάβετε ακριβώς αυτό το τμήμα.
- **Περισσότεροι τρόποι παρακολούθησης**: μεταβείτε σε πλήρη οθόνη ή διατηρήστε το βίντεο σε ένα αιωρούμενο παράθυρο Picture-in-Picture όταν είναι διαθέσιμο.
- **Κάντε το δικό σας**: επιλέξτε από 10 θέματα, από το συμπαγές Better Minimal έως τα μεγαλύτερα χειριστήρια του Better XG. Ρυθμίστε το πότε θα κρύβεται η γραμμή και ενεργοποιήστε τις συντομεύσεις πληκτρολογίου αν θέλετε.
- **Προαιρετική αποθήκευση βίντεο**: κατεβάστε συμβατά αρχεία βίντεο ή εγγράψτε ένα σύντομο κλιπ τοπικά όταν υποστηρίζεται. Αποθηκεύστε μόνο περιεχόμενο που έχετε άδεια να αντιγράψετε.

## Πού να εγκαταστήσετε

Τα παρακάτω προγράμματα περιήγησης υποστηρίζουν την εγκατάσταση μέσω του Chrome Web Store. Το Better Player έχει δοκιμαστεί σε Chrome και Edge στα Windows.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Εγκατάσταση αποθήκευσης εγγράφων Vivaldi και Yandex Browser σε Android. Το Better Player χρειάζεται ακόμα δοκιμή σε αυτά τα προγράμματα περιήγησης για κινητά. Στο Vivaldi, ενεργοποιήστε το Desktop Site. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Ο Firefox και ο Safari χρησιμοποιούν ξεχωριστά κανάλια διανομής. Η έκδοση του Firefox βρίσκεται σε δοκιμή.

## Υποστήριξη

Μετά την εγκατάσταση, ανοίξτε το Instagram στο πρόγραμμα περιήγησής σας. Κάντε κλικ στο εικονίδιο Better Player για να διαμορφώσετε τα στοιχεία ελέγχου. Όταν αναφέρετε ένα πρόβλημα, συμπεριλάβετε το πρόγραμμα περιήγησής σας, την έκδοση και τα βήματα για την αναπαραγωγή του.
