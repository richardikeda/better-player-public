# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Justera hastighet och volym för Instagram-videor, upprepa avsnitt och ladda ned kompatibla videor.

**[Installera · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [Webbplats](https://richardikeda.github.io/better-player-public/languages/sv/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [Sekretess (på portugisiska)](https://richardikeda.github.io/better-player-public/#privacidade)

## Funktioner

- **Uppspelning och ljud**: pausa, ändra hastigheten, justera volymen, dra tidslinjen eller hoppa 5 sekunder bakåt eller framåt.
- **Spela om det som är viktigt**: loopa en hel video eller markera A och B för att upprepa just det segmentet.
- **Fler sätt att titta på**: växla till helskärm eller håll videon i ett flytande bild-i-bild-fönster när det är tillgängligt.
- **Gör det till ditt**: välj mellan 10 teman, från den kompakta Better Minimal till de större kontrollerna i Better XG. Ställ in när fältet gömmer sig och aktivera kortkommandon om du vill.
- **Valfri videospara**: ladda ner kompatibla videofiler eller spela in ett kort klipp lokalt när det stöds. Spara endast innehåll som du har behörighet att kopiera.

## Var man installerar

Webbläsarna nedan stöder installation via Chrome Web Store. Better Player har testats på Chrome och Edge på Windows.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Vivaldi och Yandex Browser Document Store installation på Android. Better Player behöver fortfarande testas på dessa mobila webbläsare. Aktivera Desktop Site i Vivaldi. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox och Safari använder separata distributionskanaler. Firefox-utgåvan testas.

## Support

Efter installationen öppnar du Instagram i din webbläsare. Klicka på ikonen Better Player för att konfigurera kontrollerna. När du rapporterar ett problem, inkludera din webbläsare, version och steg för att återskapa det.
