# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Instagram動画の再生速度と音量を調整し、指定した区間を繰り返し再生したり、対応する動画をダウンロードしたりできます。

**[インストール · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [ウェブサイト](https://richardikeda.github.io/better-player-public/languages/ja/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [プライバシー (ポルトガル語)](https://richardikeda.github.io/better-player-public/#privacidade)

## 特長

- **再生とサウンド**: 一時停止、速度の変更、音量の調整、タイムラインのドラッグ、または 5 秒前または 5 秒先にジャンプします。
- 重要なものを再生します。ビデオ全体をループするか、A と B をマークしてそのセグメントだけを繰り返します。
- **その他の視聴方法**: フルスクリーンに切り替えるか、利用可能な場合はフローティング ピクチャ イン ピクチャ ウィンドウでビデオを維持します。
- **自分好みにカスタマイズ**: コンパクトな Better Minimal から大型コントロールの Better XG まで、10 のテーマから選択します。必要に応じて、バーを非表示にするタイミングを設定し、キーボード ショートカットをオンにします。
- **オプションのビデオ保存**: 互換性のあるビデオ ファイルをダウンロードするか、サポートされている場合は短いクリップをローカルに録画します。コピー権限のあるコンテンツのみを保存してください。

## 設置場所

以下のブラウザは、Chrome Web ストアからのインストールをサポートしています。 Better Player は Windows 上の Chrome と Edge でテストされています。

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Android への Vivaldi および Yandex Browser ドキュメント ストアのインストール。 Better Player は、これらのモバイル ブラウザでのテストがまだ必要です。 Vivaldi でデスクトップ サイトを有効にします。 [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox と Safari は別の配布チャネルを使用します。 Firefox 版はテスト中です。

## サポート

インストール後、ブラウザで Instagram を開きます。 Better Player アイコンをクリックしてコントロールを設定します。問題を報告するときは、使用しているブラウザ、バージョン、および問題を再現する手順を含めてください。
