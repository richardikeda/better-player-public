# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

调整 Instagram 视频的播放速度和音量，循环播放选定片段，并下载兼容的视频。

**[安装 · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [网站](https://richardikeda.github.io/better-player-public/languages/zh_CN/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [隐私（葡萄牙语）](https://richardikeda.github.io/better-player-public/#privacidade)

## 特点

- **播放和声音**:暂停、更改速度、调整音量、拖动时间线或向前或向后跳 5 秒。
- **重放重要内容**:循环播放整个视频或标记 A 和 B 以仅重复该片段。
- **更多观看方式**:切换到全屏或将视频保留在浮动画中画窗口中（如果可用）。
- **让它成为您的**:从 10 个主题中进行选择，从紧凑的 Better Minimal 到较大的 Better XG 控件。设置栏何时隐藏并根据需要打开键盘快捷键。
- **可选视频保存**:下载兼容的视频文件或在支持时在本地录制短片。仅保存您有权复制的内容。

## 安装地点

以下浏览器支持通过 Chrome Web Store 安装。 Better Player 已在 Windows 上的 Chrome 和 Edge 上进行了测试。

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Android 上的 Vivaldi 和 Yandex 浏览器文档存储安装。 Better Player 仍需要在这些移动浏览器上进行测试。在 Vivaldi 中，启用桌面站点。 [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox 和 Safari 使用不同的分发渠道。 Firefox 版本正在测试中。

## 支持

安装后，在浏览器中打开 Instagram。单击“更好的播放器”图标以配置控件。报告问题时，请提供您的浏览器、版本以及重现该问题的步骤。
