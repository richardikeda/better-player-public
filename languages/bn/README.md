# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Instagram ভিডিওর গতি ও শব্দ নিয়ন্ত্রণ করুন, অংশবিশেষ বারবার চালান এবং সামঞ্জস্যপূর্ণ ভিডিও ডাউনলোড করুন।

**[ইনস্টল করুন · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [ওয়েবসাইট](https://richardikeda.github.io/better-player-public/languages/bn/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [গোপনীয়তা (পর্তুগিজ ভাষায়)](https://richardikeda.github.io/better-player-public/#privacidade)

## বৈশিষ্ট্য

- **প্লেব্যাক এবং সাউন্ড**: বিরতি দিন, গতি পরিবর্তন করুন, ভলিউম সামঞ্জস্য করুন, টাইমলাইন টেনে আনুন বা 5 সেকেন্ড পিছনে বা এগিয়ে যান।
- **যা গুরুত্বপূর্ণ তা পুনরায় চালান**: একটি সম্পূর্ণ ভিডিও লুপ করুন বা শুধুমাত্র সেই অংশটি পুনরাবৃত্তি করতে A এবং B চিহ্নিত করুন৷
- **দেখার আরও উপায়**: ফুলস্ক্রিনে স্যুইচ করুন বা উপলব্ধ হলে একটি ভাসমান পিকচার-ইন-পিকচার উইন্ডোতে ভিডিওটি রাখুন।
- **এটিকে আপনার তৈরি করুন**: 10টি থিম থেকে বেছে নিন, কমপ্যাক্ট Better Minimal থেকে Better XG-এর বৃহত্তর নিয়ন্ত্রণ পর্যন্ত। বার লুকানোর সময় সেট করুন এবং আপনি চাইলে কীবোর্ড শর্টকাট চালু করুন।
- **ঐচ্ছিক ভিডিও সংরক্ষণ**: সামঞ্জস্যপূর্ণ ভিডিও ফাইল ডাউনলোড করুন বা সমর্থিত হলে স্থানীয়ভাবে একটি ছোট ক্লিপ রেকর্ড করুন। কপি করার অনুমতি আপনার আছে শুধুমাত্র কন্টেন্ট সংরক্ষণ করুন.

## কোথায় ইন্সটল করতে হবে

নীচের ব্রাউজারগুলি Chrome ওয়েব স্টোরের মাধ্যমে ইনস্টলেশন সমর্থন করে৷ Windows-এ Chrome এবং Edge-এ বেটার প্লেয়ার পরীক্ষা করা হয়েছে।

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** অ্যান্ড্রয়েডে ভিভাল্ডি এবং ইয়ানডেক্স ব্রাউজার ডকুমেন্ট স্টোর ইনস্টলেশন। বেটার প্লেয়ারের এখনও এই মোবাইল ব্রাউজারগুলিতে পরীক্ষার প্রয়োজন। ভিভাল্ডিতে, ডেস্কটপ সাইট সক্ষম করুন। [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

ফায়ারফক্স এবং সাফারি পৃথক বিতরণ চ্যানেল ব্যবহার করে। ফায়ারফক্স সংস্করণ পরীক্ষা চলছে।

## সমর্থন

ইনস্টল করার পরে, আপনার ব্রাউজারে Instagram খুলুন। নিয়ন্ত্রণগুলি কনফিগার করতে বেটার প্লেয়ার আইকনে ক্লিক করুন। একটি সমস্যা প্রতিবেদন করার সময়, আপনার ব্রাউজার, সংস্করণ এবং এটি পুনরুত্পাদন করার পদক্ষেপগুলি অন্তর্ভুক্ত করুন৷
