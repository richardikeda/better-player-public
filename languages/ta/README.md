# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Instagram வீடியோக்களின் வேகத்தையும் ஒலியளவையும் மாற்றுங்கள், பகுதிகளை மீண்டும் இயக்குங்கள், இணக்கமான வீடியோக்களைப் பதிவிறக்குங்கள்.

**[நிறுவு · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [இணையதளம்](https://richardikeda.github.io/better-player-public/languages/ta/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [தனியுரிமை (போர்ச்சுகீஸ் மொழியில்)](https://richardikeda.github.io/better-player-public/#privacidade)

## அம்சங்கள்

- **பின்னணி மற்றும் ஒலி**: இடைநிறுத்தவும், வேகத்தை மாற்றவும், ஒலியளவை சரிசெய்யவும், காலவரிசையை இழுக்கவும் அல்லது 5 வினாடிகள் பின்னோ அல்லது முன்னோ செல்லவும்.
- **முக்கியமானவற்றை மீண்டும் இயக்கவும்**: முழு வீடியோவையும் லூப் செய்யவும் அல்லது அந்த பகுதியை மீண்டும் செய்ய A மற்றும் B ஐக் குறிக்கவும்.
- **பார்ப்பதற்கான கூடுதல் வழிகள்**: முழுத்திரைக்கு மாறவும் அல்லது வீடியோ இருக்கும் போது படமெடுக்கும் சாளரத்தில் மிதக்கும்.
- **இதை உங்களுடையதாக ஆக்குங்கள்**: சிறிய Better Minimal முதல் Better XG இன் பெரிய கட்டுப்பாடுகள் வரை 10 தீம்களில் இருந்து தேர்வு செய்யவும். பட்டி மறையும் போது அமைக்கவும் மற்றும் நீங்கள் விரும்பினால் விசைப்பலகை குறுக்குவழிகளை இயக்கவும்.
- **விருப்ப வீடியோ சேமிப்பு**: இணக்கமான வீடியோ கோப்புகளைப் பதிவிறக்கவும் அல்லது ஆதரிக்கப்படும் போது உள்ளூரில் ஒரு சிறிய கிளிப்பை பதிவு செய்யவும். நகலெடுக்க உங்களுக்கு அனுமதி உள்ள உள்ளடக்கத்தை மட்டும் சேமிக்கவும்.

## எங்கு நிறுவ வேண்டும்

கீழே உள்ள உலாவிகள் Chrome Web Store மூலம் நிறுவலை ஆதரிக்கின்றன. Windows இல் Chrome மற்றும் Edge இல் Better Player சோதனை செய்யப்பட்டது.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** ஆண்ட்ராய்டில் விவால்டி மற்றும் யாண்டெக்ஸ் உலாவி ஆவண ஸ்டோர் நிறுவல். இந்த மொபைல் உலாவிகளில் சிறந்த பிளேயருக்கு இன்னும் சோதனை தேவை. விவால்டியில், டெஸ்க்டாப் தளத்தை இயக்கவும். [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

பயர்பாக்ஸ் மற்றும் சஃபாரி தனி விநியோக சேனல்களைப் பயன்படுத்துகின்றன. பயர்பாக்ஸ் பதிப்பு சோதனையில் உள்ளது.

## ஆதரவு

நிறுவிய பின், உங்கள் உலாவியில் Instagram ஐ திறக்கவும். கட்டுப்பாடுகளை உள்ளமைக்க பெட்டர் பிளேயர் ஐகானைக் கிளிக் செய்யவும். சிக்கலைப் புகாரளிக்கும் போது, ​​உங்கள் உலாவி, பதிப்பு மற்றும் அதை மீண்டும் உருவாக்குவதற்கான படிகளைச் சேர்க்கவும்.
