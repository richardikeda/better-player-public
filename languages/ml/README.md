# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Instagram വീഡിയോകളുടെ വേഗവും ശബ്ദവും ക്രമീകരിക്കുക, ഭാഗങ്ങൾ ആവർത്തിച്ച് പ്ലേ ചെയ്യുക, അനുയോജ്യമായ വീഡിയോകൾ ഡൗൺലോഡ് ചെയ്യുക.

**[ഇൻസ്റ്റാൾ ചെയ്യുക · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [വെബ്സൈറ്റ്](https://richardikeda.github.io/better-player-public/languages/ml/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [സ്വകാര്യത (പോർച്ചുഗീസിൽ)](https://richardikeda.github.io/better-player-public/#privacidade)

## സവിശേഷതകൾ

- **പ്ലേബാക്കും ശബ്ദവും**: താൽക്കാലികമായി നിർത്തുക, വേഗത മാറ്റുക, വോളിയം ക്രമീകരിക്കുക, ടൈംലൈൻ വലിച്ചിടുക, അല്ലെങ്കിൽ 5 സെക്കൻഡ് പിന്നോട്ടോ മുന്നിലോ ചാടുക.
- **പ്രധാനപ്പെട്ടത് വീണ്ടും പ്ലേ ചെയ്യുക**: ഒരു മുഴുവൻ വീഡിയോയും ലൂപ്പ് ചെയ്യുക അല്ലെങ്കിൽ ആ സെഗ്മെൻ്റ് ആവർത്തിക്കാൻ A, B എന്നിവ അടയാളപ്പെടുത്തുക.
- **കാണാനുള്ള കൂടുതൽ വഴികൾ**: ഫുൾസ്‌ക്രീനിലേക്ക് മാറുക അല്ലെങ്കിൽ വീഡിയോ ലഭ്യമാകുമ്പോൾ ഒരു ഫ്ലോട്ടിംഗ് പിക്ചർ-ഇൻ-പിക്ചർ വിൻഡോയിൽ സൂക്ഷിക്കുക.
- **ഇത് നിങ്ങളുടേതാക്കുക**: കോംപാക്റ്റ് Better Minimal മുതൽ Better XG-ൻ്റെ വലിയ നിയന്ത്രണങ്ങൾ വരെയുള്ള 10 തീമുകളിൽ നിന്ന് തിരഞ്ഞെടുക്കുക. ബാർ മറയ്‌ക്കുമ്പോൾ സജ്ജീകരിക്കുക, നിങ്ങൾക്ക് താൽപ്പര്യമുണ്ടെങ്കിൽ കീബോർഡ് കുറുക്കുവഴികൾ ഓണാക്കുക.
- **ഓപ്ഷണൽ വീഡിയോ സേവിംഗ്**: അനുയോജ്യമായ വീഡിയോ ഫയലുകൾ ഡൗൺലോഡ് ചെയ്യുക അല്ലെങ്കിൽ പിന്തുണയ്ക്കുമ്പോൾ ഒരു ചെറിയ ക്ലിപ്പ് പ്രാദേശികമായി റെക്കോർഡ് ചെയ്യുക. നിങ്ങൾക്ക് പകർത്താൻ അനുമതിയുള്ള ഉള്ളടക്കം മാത്രം സംരക്ഷിക്കുക.

## എവിടെ ഇൻസ്റ്റാൾ ചെയ്യണം

ചുവടെയുള്ള ബ്രൗസറുകൾ Chrome വെബ് സ്റ്റോർ വഴിയുള്ള ഇൻസ്റ്റാളേഷനെ പിന്തുണയ്ക്കുന്നു. Chrome-ലും Windows-ലെ Edge-ലും Better Player പരീക്ഷിച്ചു.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** ആൻഡ്രോയിഡിൽ Vivaldi, Yandex ബ്രൗസർ ഡോക്യുമെൻ്റ് സ്റ്റോർ ഇൻസ്റ്റാളേഷൻ. ഈ മൊബൈൽ ബ്രൗസറുകളിൽ മികച്ച പ്ലെയറിന് ഇപ്പോഴും പരിശോധന ആവശ്യമാണ്. വിവാൾഡിയിൽ, ഡെസ്ക്ടോപ്പ് സൈറ്റ് പ്രവർത്തനക്ഷമമാക്കുക. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

ഫയർഫോക്സും സഫാരിയും പ്രത്യേക വിതരണ ചാനലുകൾ ഉപയോഗിക്കുന്നു. ഫയർഫോക്സ് പതിപ്പ് പരീക്ഷണത്തിലാണ്.

## പിന്തുണ

ഇൻസ്റ്റാൾ ചെയ്ത ശേഷം, നിങ്ങളുടെ ബ്രൗസറിൽ Instagram തുറക്കുക. നിയന്ത്രണങ്ങൾ കോൺഫിഗർ ചെയ്യാൻ ബെറ്റർ പ്ലെയർ ഐക്കണിൽ ക്ലിക്ക് ചെയ്യുക. ഒരു പ്രശ്നം റിപ്പോർട്ടുചെയ്യുമ്പോൾ, നിങ്ങളുടെ ബ്രൗസറും പതിപ്പും അത് പുനർനിർമ്മിക്കാനുള്ള ഘട്ടങ്ങളും ഉൾപ്പെടുത്തുക.
