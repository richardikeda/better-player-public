# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Instagram વિડિયોની ગતિ અને અવાજ બદલો, કોઈ ભાગ ફરી ચલાવો અને સુસંગત વિડિયો ડાઉનલોડ કરો.

**[ઇન્સ્ટોલ કરો · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [વેબસાઈટ](https://richardikeda.github.io/better-player-public/languages/gu/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [ગોપનીયતા (પોર્ટુગીઝમાં)](https://richardikeda.github.io/better-player-public/#privacidade)

## લક્ષણો

- **પ્લેબેક અને ધ્વનિ**: થોભો, ઝડપ બદલો, વોલ્યુમ સમાયોજિત કરો, સમયરેખા ખેંચો અથવા 5 સેકન્ડ પાછળ અથવા આગળ જાઓ.
- **શું મહત્વનું છે તે ફરીથી ચલાવો**: સંપૂર્ણ વિડિઓ લૂપ કરો અથવા ફક્ત તે સેગમેન્ટને પુનરાવર્તિત કરવા માટે A અને B ચિહ્નિત કરો.
- **જોવાની વધુ રીતો**: પૂર્ણસ્ક્રીન પર સ્વિચ કરો અથવા ઉપલબ્ધ હોય ત્યારે વિડિયોને ફ્લોટિંગ પિક્ચર-ઇન-પિક્ચર વિંડોમાં રાખો.
- **તેને તમારું બનાવો**: 10 થીમ્સમાંથી પસંદ કરો, કોમ્પેક્ટ Better Minimal થી લઈને Better XG ના મોટા નિયંત્રણો સુધી. જ્યારે બાર છુપાવે ત્યારે સેટ કરો અને જો તમને ગમે તો કીબોર્ડ શૉર્ટકટ્સ ચાલુ કરો.
- **વૈકલ્પિક વિડિઓ બચત**: સુસંગત વિડિઓ ફાઇલો ડાઉનલોડ કરો અથવા જ્યારે સમર્થિત હોય ત્યારે સ્થાનિક રીતે ટૂંકી ક્લિપ રેકોર્ડ કરો. તમને કૉપિ કરવાની પરવાનગી હોય એવી સામગ્રી જ સાચવો.

## ક્યાં સ્થાપિત કરવું

નીચેના બ્રાઉઝર્સ Chrome વેબ દુકાન દ્વારા ઇન્સ્ટોલેશનને સમર્થન આપે છે. Windows પર Chrome અને Edge પર બેટર પ્લેયરનું પરીક્ષણ કરવામાં આવ્યું છે.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Android પર Vivaldi અને Yandex Browser દસ્તાવેજ સ્ટોર ઇન્સ્ટોલેશન. બેટર પ્લેયરને હજી પણ આ મોબાઇલ બ્રાઉઝર્સ પર પરીક્ષણની જરૂર છે. વિવાલ્ડીમાં, ડેસ્કટોપ સાઇટને સક્ષમ કરો. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

ફાયરફોક્સ અને સફારી અલગ-અલગ વિતરણ ચેનલોનો ઉપયોગ કરે છે. Firefox આવૃત્તિ પરીક્ષણમાં છે.

## આધાર

ઇન્સ્ટોલ કર્યા પછી, તમારા બ્રાઉઝરમાં Instagram ખોલો. નિયંત્રણોને ગોઠવવા માટે બેટર પ્લેયર આયકન પર ક્લિક કરો. સમસ્યાની જાણ કરતી વખતે, તમારું બ્રાઉઝર, સંસ્કરણ અને તેને પુનઃઉત્પાદિત કરવાનાં પગલાં શામેલ કરો.
