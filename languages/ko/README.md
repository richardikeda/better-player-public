# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Instagram 동영상의 재생 속도와 음량을 조절하고, 구간을 반복 재생하며, 호환되는 동영상을 다운로드하세요.

**[설치 · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [웹사이트](https://richardikeda.github.io/better-player-public/languages/ko/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [개인정보 보호(포르투갈어)](https://richardikeda.github.io/better-player-public/#privacidade)

## 특징

- **재생 및 사운드**: 일시 정지, 속도 변경, 볼륨 조정, 타임라인 드래그, 5초 앞뒤로 이동 등이 가능합니다.
- 중요한 내용을 재생하세요. 전체 동영상을 반복 재생하거나 A와 B를 표시하여 해당 부분만 반복하세요.
- **다양한 시청 방법**: 전체 화면으로 전환하거나 가능한 경우 부동 Picture-in-Picture 창에 비디오를 유지합니다.
- **나만의 것으로 만드세요**: 컴팩트한 Better Minimal부터 더 큰 컨트롤의 Better XG까지 10가지 테마 중에서 선택하세요. 원하는 경우 막대가 숨겨지는 시기를 설정하고 키보드 단축키를 켭니다.
- **선택적 비디오 저장**: 지원되는 경우 호환되는 비디오 파일을 다운로드하거나 짧은 클립을 로컬로 녹화합니다. 복사 권한이 있는 콘텐츠만 저장하세요.

## 설치 위치

아래 브라우저는 Chrome 웹 스토어를 통한 설치를 지원합니다. Better Player는 Windows의 Chrome 및 Edge에서 테스트되었습니다.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Android에 Vivaldi 및 Yandex Browser 문서 저장소 설치. Better Player는 여전히 이러한 모바일 브라우저에서 테스트가 필요합니다. 비발디에서 데스크탑 사이트를 활성화하세요. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox와 Safari는 별도의 배포 채널을 사용합니다. Firefox 버전은 테스트 중입니다.

## 지원

설치 후 브라우저에서 Instagram을 엽니다. Better Player 아이콘을 클릭하여 컨트롤을 구성하세요. 문제를 보고할 때 브라우저, 버전, 문제 재현 단계를 포함하세요.
