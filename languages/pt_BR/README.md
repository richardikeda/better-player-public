# Better Player

**[Português (Brasil)](../../README.md) · [English](../en/README.md) · [Other Languages](../README.md)**

Ajuste a velocidade e o volume dos vídeos do Instagram, repita trechos e baixe vídeos compatíveis.

**[Instalar · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [Site](https://richardikeda.github.io/better-player-public/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [Privacidade](https://richardikeda.github.io/better-player-public/#privacidade)

## Recursos

- **Reprodução e som**: pause, mude a velocidade, ajuste o volume, arraste a barra de progresso ou pule 5 segundos para frente ou para trás.
- **Repita só o que interessa**: deixe o vídeo em repetição ou marque A e B para rever um trecho.
- **Mais formas de assistir**: use a tela cheia ou mantenha o vídeo em uma janela flutuante com o modo picture-in-picture, quando disponível.
- **Deixe o player com a sua cara**: escolha entre 10 temas, do Better Minimal compacto aos controles maiores do Better XG. Defina quando a barra se esconde e ative atalhos de teclado se preferir.
- **Salvamento opcional**: baixe arquivos de vídeo compatíveis ou grave um trecho curto no navegador, quando houver suporte. Salve apenas conteúdos que você tem permissão para copiar.

## Onde instalar

Os navegadores abaixo permitem instalar extensões pela Chrome Web Store. O Better Player foi testado no Chrome e no Edge para Windows.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Vivaldi e Yandex Browser documentam a instalação pela loja no Android. O Better Player ainda precisa ser testado nesses navegadores móveis. No Vivaldi, ative a opção Site para computador. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox e Safari usam canais próprios de distribuição. A edição do Firefox está em testes.

## Suporte

Após instalar, abra o Instagram no navegador. Clique no ícone do Better Player para configurar os controles. Ao relatar um problema, informe o navegador, a versão e os passos para reproduzi-lo.
