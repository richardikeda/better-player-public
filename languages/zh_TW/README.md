# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

調整 Instagram 影片的播放速度與音量、重複播放指定片段，並下載相容的影片。

**[安裝 · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [網站](https://richardikeda.github.io/better-player-public/languages/zh_TW/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [隱私（葡萄牙語）](https://richardikeda.github.io/better-player-public/#privacidade)

## 特點

- **播放與聲音**:暫停、變更速度、調整音量、拖曳時間軸或向前或向後跳 5 秒。
- **重播重要內容**:循環播放整個影片或標記 A 和 B 以僅重複該片段。
- **更多觀看方式**:切換到全螢幕或將影片保留在浮動畫中畫視窗中（如果可用）。
- **讓它成為您的**:從 10 個主題中進行選擇，從緊湊的 Better Minimal 到較大的 Better XG 控制。設定欄何時隱藏並根據需要開啟鍵盤快速鍵。
- **可選視訊保存**:下載相容的視訊檔案或在支援時在本地錄製短片。僅保存您有權複製的內容。

## 安裝地點

以下瀏覽器支援透過 Chrome Web Store 安裝。 Better Player 已在 Windows 上的 Chrome 和 Edge 上進行了測試。

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Android 上的 Vivaldi 和 Yandex 瀏覽器文件儲存安裝。 Better Player 仍需要在這些行動瀏覽器上進行測試。在 Vivaldi 中，啟用桌面網站。 [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox 和 Safari 使用不同的發行管道。 Firefox 版本正在測試中。

## 支援

安裝後，在瀏覽器中開啟 Instagram。按一下「更好的播放器」圖示以配置控制項。回報問題時，請提供您的瀏覽器、版本以及重現問題的步驟。
