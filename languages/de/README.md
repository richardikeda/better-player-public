# Better Player

**[Português (Brasil)](../../README.md) · [English](../../languages/en/README.md) · [Other Languages](../../languages/README.md)**

Passe Tempo und Lautstärke von Instagram-Videos an, wiederhole Ausschnitte und lade kompatible Videos herunter.

**[Installieren · Chrome Web Store](https://chromewebstore.google.com/detail/better-player/abapegnadkbbldnohmmbcklpicommlik)** · [Website](https://richardikeda.github.io/better-player-public/languages/de/) · [GitHub Issues](https://github.com/richardikeda/better-player-public/issues) · [Datenschutz (auf Portugiesisch)](https://richardikeda.github.io/better-player-public/#privacidade)

## Funktionen

- **Wiedergabe und Ton**: Pause, Geschwindigkeit ändern, Lautstärke anpassen, Zeitleiste verschieben oder 5 Sekunden vor oder zurück springen.
- **Spielen Sie das Wesentliche noch einmal ab**: Wiederholen Sie ein ganzes Video oder markieren Sie A und B, um nur diesen Abschnitt zu wiederholen.
- **Weitere Möglichkeiten zum Ansehen**: Wechseln Sie zum Vollbild oder lassen Sie das Video in einem schwebenden Bild-in-Bild-Fenster, sofern verfügbar.
- **Machen Sie es zu Ihrem**: Wählen Sie aus 10 Themen, vom kompakten Better Minimal bis zu den größeren Bedienelementen des Better XG. Legen Sie fest, wann die Leiste ausgeblendet wird, und aktivieren Sie bei Bedarf Tastaturkürzel.
- **Optionale Videospeicherung**: Laden Sie kompatible Videodateien herunter oder zeichnen Sie einen kurzen Clip lokal auf, sofern dies unterstützt wird. Speichern Sie nur Inhalte, für deren Kopieren Sie berechtigt sind.

## Wo zu installieren

Die folgenden Browser unterstützen die Installation über den Chrome Web Store. Better Player wurde auf Chrome und Edge unter Windows getestet.

[Chrome](https://support.google.com/chrome/answer/2664769) · [ChromeOS](https://support.google.com/chromebook/answer/2588006) · [Edge](https://support.microsoft.com/en-us/edge/add-turn-off-or-remove-extensions-in-microsoft-edge) · [Brave](https://support.brave.app/hc/en-us/articles/360017909112-How-can-I-add-extensions-to-Brave) · [Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) · [Opera](https://help.opera.com/en/faq/) · [Yandex Browser](https://yandex.com/support/browser/en/personalization/extension) · [Dia](https://resources.arc.net/hc/en-us/articles/44413577819159-Arc-Sunset-Frequently-Asked-Questions)

**Android.** Installation des Vivaldi- und Yandex-Browser-Dokumentenspeichers auf Android. Better Player muss noch auf diesen mobilen Browsern getestet werden. Aktivieren Sie in Vivaldi die Desktop-Site. [Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) · [Yandex Browser](https://yandex.com/support/browser-mobile-android-phone/en/personal-settings/extensions)

Firefox und Safari nutzen separate Vertriebskanäle. Die Firefox-Edition befindet sich im Test.

## Unterstützung

Öffnen Sie nach der Installation Instagram in Ihrem Browser. Klicken Sie auf das Better Player-Symbol, um die Steuerelemente zu konfigurieren. Wenn Sie ein Problem melden, geben Sie Ihren Browser, Ihre Version und die Schritte zur Reproduktion an.
